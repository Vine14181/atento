# Manual de Execução: Atento

Este documento é a diretriz oficial de execução do projeto "Atento". Siga estritamente as instruções e arquiteturas definidas aqui para construir o aplicativo.

## Propósito do App
Construa um sistema focado em proteger a Memória de Trabalho (RAM do cérebro) e evitar a Procrastinação e Paralisia de usuários com TDAH.

## Resumo da Arquitetura e Funcionalidades (Obrigatório)
1. **Frontend e Visual:** FAÇA um PWA utilizando React. Implemente o design "Linear-style" / Shadcn UI em Dark Mode, garantindo espaço negativo e ausência de ruído visual.
2. **Backend e Nuvem:** CONFIGURE o Firebase (Autenticação Google e Banco de Dados Firestore) e HOSPEDE no Netlify para garantir acesso unificado (Mobile e Desktop).
3. **Espinha Dorsal (Lógica de IA):** INTEGRE a API do Google Gemini (1.5 Pro/Flash) para processar as lógicas de organização mental e quebra de tarefas.

*Siga os manuais detalhados (arquivos 2, 3 e 4) para a execução de cada módulo.*
